# MEVIX · نظام الإدارة

## الأقسام
- **العملاء:** مراحل الاتفاق، الحالة بكلامك، السجل، ملف العميل، اتفاق الدفعات.
- **المشاريع:** جديد / شغال / خلصناه، الأدوار وملفاتها، الدفعات والتكاليف، بيانات الدخول، ملفات الفريق والملفات النهائية، البريف عربي/إنجليزي.
- **المهام والمتابعة اليومية والشكاوى.**
- **المساعد:** نص وفويس وملفات، وكل واحد يشوف اللي مسموح له بس.
- **المالية:** دخلك، خزنة الشركة، صندوق الاشتراكات، مستحقات الفريق، شهر بشهر.

## الأساس
- تسجيل دخول آمن: قفل الحساب 15 دقيقة بعد 5 محاولات خاطئة، والجلسة تنتهي بعد 10 ساعات.
- الصلاحيات: مدير، تيم ليد، عضو فريق. صفحات الإدارة للمدير فقط، والتحقق يتم على السيرفر في كل طلب.
- الموظفون: إضافة موظف باسم مستخدم وكلمة مرور، تغيير كلمة المرور، إيقاف الحساب أو إعادة تفعيله، وحذف نهائي.
- الموردون: VPS، وAPI، ومزود واتساب، وأخرى.
- الإعدادات: نسب التوزيع، قواعد الخصم، أسعار الصرف، المصاريف الثابتة، ومفتاح OpenRouter مشفّر مع اختبار الاتصال.

## التثبيت على VPS من Hostinger
1. من لوحة Hostinger، اختر نظام **Ubuntu 24.04** للـ VPS.
2. ارفع مجلد المشروع للسيرفر، مثلاً على المسار `/opt/mevix`.
3. ادخل على السيرفر بـ SSH، ونفّذ:
   ```bash
   cd /opt/mevix
   bash deploy/install.sh
   ```
4. السكريبت هيسألك عن اسم المستخدم وكلمة المرور بتوعك، وبعدها يركّب كل حاجة، ويطبع كلمات مرور الفريق مرة واحدة. **احفظها.**
5. افتح `https://IP-السيرفر`. المتصفح هيظهر تحذير أمان لأن مفيش دومين. اختار "متابعة".

## لما يبقى عندك دومين
1. وجّه الدومين على IP السيرفر من خلال سجل A.
2. في ملف `.env` غيّر `SITE_ADDRESS=https://system.yourdomain.com`.
3. احذف سطر `tls internal` من ملف `Caddyfile`.
4. نفّذ `bash deploy/update.sh`. الشهادة الموثوقة هتتعمل تلقائياً، والتحذير هيختفي.

## التحديث
بعد رفع نسخة جديدة من الكود: `bash deploy/update.sh`

## الباك أب
نسخة يومية من قاعدة البيانات في `/var/backups/mevix`، والنظام بيحتفظ بآخر 14 يوم.

## أمان السيرفر (السكريبت بيعمله تلقائياً)
- الفايروول يسمح بـ SSH و80 و443 بس. قاعدة البيانات مش مكشوفة على الإنترنت.
- Fail2ban بيحظر محاولات تخمين كلمة مرور SSH.
- تحديثات الأمان بتتركب تلقائياً.

**يُنصح كمان:** تدخل على SSH بمفتاح بدل كلمة المرور. اعمل المفتاح من لوحة Hostinger، وبعدها اقفل الدخول بكلمة المرور.
